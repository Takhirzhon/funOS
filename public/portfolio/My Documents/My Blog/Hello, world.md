# Hello, world

This is the first post on a blog that lives inside a Windows XP desktop, which lives inside a browser tab. If you are reading it in Internet Explorer 6 with a Bliss wallpaper behind it, everything is working.

## Why XP

Because it is the desktop I learned computers on, and because a portfolio should be something you want to click around in. A PDF is a PDF. A desktop with a Recycle Bin you can actually drag things into is a place.

## How the blog works

Each post is a Markdown file in `My Documents\My Blog`. You can find them in Explorer and open them like any other file - they open here, in the browser, rather than in Notepad. There is an [RSS feed](https://khirokhito.tech/rss.xml) too, for the three people who still use one. I am one of them.

## What is next

More about the things I actually work on - LLM evaluation, red-teaming, the audio pipeline - and less about the desktop. Though the desktop is not finished either. There is a list.
